# Arduino LED Blink with Push Button

## Project Overview

This project demonstrates a basic Arduino IoT experiment using an Arduino UNO, LED, resistor, and push button. The circuit was designed and tested virtually using Tinkercad Circuits.

## Components

- Arduino UNO
- LED
- 220Ω resistor
- Push button
- Breadboard
- Jumper wires

## Connections

- LED → Digital Pin 13
- Push Button → Digital Pin 2
- LED → 220Ω resistor → GND
- Push Button → GND

## Features

- LED blinking
- Push button input
- GPIO output and input
- Internal pull-up resistor
- Basic button handling
- setup() and loop() structure

## Software Used

- Tinkercad Circuits
- Arduino C/C++

## Working

When the push button is not pressed, the LED blinks continuously. When the push button is pressed, the LED turns ON.

## Simulation

The complete circuit was implemented and tested virtually in Tinkercad Circuits.
